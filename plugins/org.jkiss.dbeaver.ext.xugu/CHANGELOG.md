## v1.3.0 - DBeaver 21.2.4

### 新增功能

- 适配 DBeaver 21.2.4 版本
- 新增 CON[NECT] 与 USE 命令修改连接信息并执行重新连接，语法如下：  
  **注意：当信息（如用户名）中，包含有 `/@:` 字符时，请使用双引号包裹整段数据**  
  **限制：数据中含有双引号 `"` 时，无法正常使用此功能**  
  **示例：CONNECT U1/"TEST@123"@localhost:5138/SYSTEM** 
  - `CON[NECT] 用户名/密码@主机:端口/库名`   
  - `USE 库名`
- 新增 编辑框标题显示连接状态标记[√][×]、登录库与登录用户
- 新增 项目脚本文件窗口新增对应的编辑框标题列
- 新增 未连接的编辑框在执行命令时自动连接
- 新增 执行 SQL 脚本并导出为一个 XLSX 文件功能，一个查询为一个工作表
- 新增 授予对象权限时缺少参数提示
- 新增 虚谷数据库定时作业功能，创建、删除、编辑、启用、禁用、执行
- 新增 从 SQL 文件导入数据功能
- 新增 数据库备份，支持系统、库、模式、表级备份
- 新增 数据库恢复，支持系统、库、模式、表级恢复
- 新增 同义词、全局同义词、序列值、角色、用户对象的生成SQL功能
- 新增 数据库事务查杀功能

### 移除功能

- 移除 启动时自动连接已打开编辑框的连接
- 移除 包中存储过程与存储函数下的冗余参数文件夹层级

### 修改功能
